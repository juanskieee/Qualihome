# Qualihome — Issues & Feature Checklist
**Project:** Qualihome (Flask + Render + Aiven MySQL)  
**Date:** 2026-08-13  
**Source:** Admin/Client/Agent Side PDF walkthrough

---

## ADMIN SIDE

### Issue 1 — Auto Pricing Breakdown on Model Creation
**Description:** When admin fills in model details and clicks Create, a Full Pricing Breakdown should automatically appear below the form.  
**Breakdown includes:** VAT, LMF, Downpayment, Amortization Schedule (5/10/15/20 yr), Required Income.  
**Missing behavior:** If `Annual Interest Rate` is blank, system should prompt/remind admin to fill it in before the breakdown renders.

---

### Issue 2 — Availability Status on Model Creation
**Description:** Admin should be able to set availability status (`Available`, `Reserved`, `Sold`) directly during model creation, not just after.  
**Current state:** Dropdown appears to exist — verify it is functional at create time, not only on edit.

---

### Issue 3 — Subdivision Address Auto-inherited by Model
**Description:**  
- Subdivision stores: `city`, `province`, `barangay`  
- Project stores: `name`, `description`, `picture` only (no address fields)  
- When a model (house) is created under a subdivision, its address should **automatically inherit** the subdivision's city/province/barangay — admin should not manually re-enter it.

**Expected:** Model address = Subdivision address, populated automatically on create.

---

### Issue 4 — Qualification Reports Page — Add Explanations/Tooltips
**Description:** The DTI Qualification Thresholds config section on the Qualification Reports page has no explanation text.  
**Expected:** Add labels, tooltips, or helper text explaining:
- What DTI means
- How each threshold (Qualified Max, Conditional Max, Not Qualified Above) affects classification
- Example values (e.g., DTI ≤ 35% = Qualified, 35–42% = Conditional, >42% = Not Qualified)

---

### Issue 5 — C5.0 AI Management (ML Engine)
**Description:** Engine works correctly once a dataset is uploaded.  
**Status:** ✅ Working — no action needed. Confirmed functional with training data present.

---

### Issue 6 — Notification Indicators / Badge Count
**Description:** No notification badges are currently showing.  
**Expected behavior:**
- Badge/indicator appears on **Tripping Requests** nav item when a new tripping request comes in (e.g., shows `1`)
- Separate badge/indicator appears when a client requests a **View Full Pricing Breakdown** on a model
- Both should function like standard notification counters (increment on new request, clear on view)

---

## CLIENT SIDE

### Issue 7 — Browse by Year → Qualified / Conditional / Not Qualified Split
**Description:** When client selects a qualification year (5, 10, 15, 20 yrs), all models should load and be split into 3 sections:
1. ✅ Qualified
2. ⚠️ Conditional
3. ❌ Not Qualified

**Expected:** Client can check all year ranges up to 20 years, switching between them to see different qualification splits.

---

### Issue 8 — Similarity Score Display (Remove 99%, Show Label)
**Description:** The old flat "99%" similarity score was removed.  
**New behavior:** Replace with a `High / Moderate / Low Similarity` label.  
**Missing:** When similarity is `Low` or `Moderate`, it should be **prominently visible** on the model card — not hidden or subtle.

---

### Issue 9 — Model Detail: Qualified vs Conditional Indicator + Conditional Requirements Button
**Description:** When a client clicks on a model:
- Year selector appears — qualification status updates based on selected year
- If **Qualified** → show green qualified status
- If **Conditional** → show yellow status + display a **"Conditional Requirements"** yellow button

**When "Conditional Requirements" button is clicked, show modal with:**
- Need a Co-Borrower
- Longer Loan Term
- Larger Down Payment
- Improve Employment Stability

**Bottom of modal:** Contact info for agent Ann Regar — include social media links and phone number.

---

### Issue 10 — View Price Breakdown (Client)
**Description:** When client clicks "View Full Pricing Breakdown" on a model, they should see the **same full breakdown** as the admin (Issue 1):  
VAT, LMF, Reservation Fee, Total Contract Price, Monthly Downpayment, Loanable Amount, Annual Interest, Amortization table, Required Income.

---

### Issue 11 — Qualified Models Section (Home Page)
**Description:** "Qualified Models for You" section on home page should only show models the client actually qualifies for (at any year range — 5, 10, 15, or 20 yrs).  
**"Recommended for You"** section is based on preferences set during client signup.

---

## AGENT SIDE

### Issue 12 — Agent Model View: Read-Only + Full Breakdown Visible
**Description:** When an agent views a model, the view should be **read-only** — no edit controls.  
**Agent should still see:** Full Pricing Breakdown (same as admin/client breakdown).  
**Current bug (to verify):** Edit fields may still be accessible to agents — should be disabled or hidden entirely.
