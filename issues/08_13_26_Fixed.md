## ADMIN SIDE

### Issue 1 — Auto Full Pricing Breakdown on Model Create ✅ Fixed
**Backend (`app/main/routes.py`)**
- Refactored the inline pricing math into two reusable helpers:
  - `_resolve_pricing_inputs(overrides)` (line 377) — pulls defaults from SystemConfig and merges overrides.
  - `_compute_pricing_values(values)` (line 414) — does the actual computation (TCP, net, reservation, DP, loanable, VAT, LMF, amortization, required income).
  - `_compute_property_pricing(property_item)` (line 487) — thin wrapper used by all dashboards so every view uses one source of truth.
- Added admin-only GET endpoint `/admin/property/pricing-preview` (line 501), gated with `@login_required` + role check (`403` for non-admin).

**Frontend (`app/templates/dashboard/admin.html`, `app/static/js/admin_dashboard.js`)**
- Create modal now has an **Annual Interest Rate** input (prefilled from `default_annual_interest_rate`).
- A live **Full Pricing Breakdown** preview renders below the form as the admin types (debounced 300 ms), including TCP, Net Contract, Total Contract Price, Monthly Downpayment, Loanable Amount, VAT/LMF, amortization + required income for 5/10/15/20-year terms.
- If the Annual Interest Rate is blank, the system shows a warning and hides the amortization rows instead of rendering.

### Issue 2 — Availability Status on Model Create ✅ Fixed
- `agent_submit_property` now reads `status` from the form (`available` / `reserved` / `sold`, default `available`) and persists it (routes.py:3063).
- Create response returns `listing_status` (routes.py:3146).
- Admin JS `_pushNewPropertyCard` renders the correct badge (Available / Reserved / Sold) immediately on create — primary response path and fallback both pass the chosen status. No edit-save cycle needed.

### Issue 3 — Model Auto-Inherits Subdivision Address ✅ Verified
- Backend already inherits Region / Province / City / Barangay (name + PSGC code) from the selected subdivision (routes.py:3029-3038).
- Admin JS `_applyAcpSubdivisionMeta` auto-fills the disabled PSGC selects when a subdivision is chosen.
- No further change required.

### Issue 4 — DTI Explanations in Qualification Reports ✅ Fixed

### Issue 5 — C5.0 ML Engine ✅ Verified Working (no change)

### Issue 6 — Notification Badge Counts ✅ Fixed
